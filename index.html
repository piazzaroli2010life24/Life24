Política de Privacidade do LIFE24h

Data de vigência: 03 de novembro de 2026

1. Dados Coletados

Para oferecer as funcionalidades do LIFE24h, coletamos:

  • Dados de Conta: Endereço de e-mail e senha (criptografada).
  • Perfil: Nome de usuário e foto de perfil.
  • Conteúdo Criado: Textos e imagens publicadas.

2. Uso dos Dados

Utilizamos seus dados para gerenciar sua conta, exibir seu perfil/publicações e armazenar conteúdo com segurança via Supabase.

3. Compartilhamento

Não compartilhamos dados com terceiros para marketing. Utilizamos a infraestrutura do Supabase para banco de dados e autenticação.

4. Direitos do Usuário

Você pode excluir suas publicações pelo app ou solicitar a exclusão de sua conta e dados entrando em contato conosco.
